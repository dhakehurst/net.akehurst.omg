# OCL fixes in uml_patched.xmi

`uml_patched.xmi` is a copy of the OMG UML 2.5.1 XMI (`UML_2-5-1_ASM_ptc-18-01-01.xmi`, kept as published next to it) with the edits below. The UML api, ram and agl-types modules are generated from the patched file.

| Rule | was | now | Why |
|---|---|---|---|
| Classifier::directlyUsedInterfaces (body) | `supplierDependency->select(oclIsKindOf(Usage) and client->forAll(oclIsKindOf(Interface)))->collect(client.oclAsType(Interface))->asSet()` | `clientDependency->select(oclIsKindOf(Usage) and supplier->forAll(oclIsKindOf(Interface)))->collect(supplier.oclAsType(Interface))->asSet()` | The published rule navigates `supplierDependency`, a non-navigable association end, and reads backwards: it collects the clients of the Usages whose supplier is this Classifier. The operation's comment ("The Interfaces directly used by this Classifier"), the spec text for Port::required and the Eclipse UML2 implementation all mean the Interfaces that are suppliers of this Classifier's own Usages. |
| Extension::metaclassEnd (body) | `memberEnd->reject(p \| ownedEnd->includes(p.oclAsType(ExtensionEnd)))->any(true)` | `memberEnd->reject(p \| ownedEnd->includes(p))->any(true)` | `p.oclAsType(ExtensionEnd)` is invalid for the end typed by the metaclass, which is a plain Property, so the rule failed on every Extension. |
| Action::containingBehavior (body) | `... else interaction endif` | `... else if activity<>null then activity.oclAsType(Behavior) else if owner.oclIsKindOf(Interaction) then owner.oclAsType(Behavior) else null endif ...` | `interaction` is a non-navigable association end; an Action in an Interaction is owned by it. The casts give both branches the same type. |
| Behavior::context (body and derivation) | `if nestingClass <> null then null else let b = self.behavioredClassifier(self.owner) in ...` | `if owner.oclIsKindOf(Class) and owner.oclAsType(Class).nestedClassifier->includes(self) then null else let b = if owner = null then null else self.behavioredClassifier(self.owner) endif in ...` | `nestingClass` is a non-navigable association end (the opposite of Class::nestedClassifier); `behavioredClassifier` must not be called with no owner. |
| Behavior::behavioredClassifier (body) | the rule is a `precondition` of the operation, with no `result =` | the operation's `bodyCondition`, `result = if from.oclIsKindOf(BehavioredClassifier) ...` (same expression) | The rule is the body of the query, as its comment says. |
| ConnectorEnd::definingEnd (body and derivation) | `if connector.type = null then null else let index = connector.end->indexOf(self) in connector.type.memberEnd->at(index) endif` | the same with `owner.oclAsType(Connector)` for `connector`, and `null` when the owner is not a Connector | `connector` is a non-navigable association end; a ConnectorEnd is owned by its Connector. |
| ExtensionEnd::lower (derivation) | none | `result = (lowerBound())` (new rule `ExtensionEnd-lower-derivation` on ExtensionEnd) | The derived `lower` had no derivation; ExtensionEnd::lowerBound() is its redefined value (0 when there is no lowerValue). |
| Message::messageKind (derivation) | `messageKind` | `if sendEvent <> null and receiveEvent <> null then MessageKind::complete else if sendEvent <> null then MessageKind::lost else if receiveEvent <> null then MessageKind::found else MessageKind::unknown endif endif endif` | The rule was the property itself (circular). The new rule is the spec text of MessageKind (complete: both events present; lost: no receiveEvent; found: no sendEvent; unknown: neither). |
| Parameter::default (body and derivation) | `if self.type = String then defaultValue.stringValue() else null endif` | `if defaultValue = null then null else defaultValue.stringValue() endif` | `String` (the primitive type) is not a name in the metamodel. The string value of any default is used, as in Eclipse UML2. |
| Package::makesVisible (body) | `ownedMember->includes(el) or elementImport->select(ei \| ei.importedElement = VisibilityKind::public)... or packageImport->select(visibility = VisibilityKind::public)->collect(importedPackage.member->includes(el))->notEmpty()` | `Set{self}->closure(q \| q.packageImport->select(pi \| pi.visibility = VisibilityKind::public).importedPackage)->exists(p \| p.ownedMember->includes(el) or p.elementImport->select(ei \| ei.visibility = VisibilityKind::public)->exists(ei \| ei.importedElement = el))` | `ei.importedElement` was compared with a VisibilityKind (`ei.visibility` is meant); `collect(...)->notEmpty()` was true whenever there was a public import; and following `importedPackage.member` recursively never ends when packages import each other (as the packages of the UML metamodel do). The closure over public package imports gives the same elements and stops on cycles. |
| Package::visibleMembers (body) | `member->select(m \| m.oclIsKindOf(PackageableElement) and self.makesVisible(m))->collect(oclAsType(PackageableElement))->asSet()` | the owned members and publicly element-imported elements of every package in the same closure, that are PackageableElements | Through `member` (which includes `importedMember`, which uses the visibleMembers of the imported packages) it never ended for packages that import each other. |
| Namespace::getNamesOfMember (body) | recursive: `... else packageImport->select(pi \| pi.importedPackage.visibleMembers()...->includes(element))->collect(pi \| pi.importedPackage.getNamesOfMember(element))` | `Set{self}->closure(n \| n.packageImport->select(pi \| not (n.ownedMember->includes(element) or n.elementImport->exists(ei \| ei.importedElement = element)) and pi.importedPackage.visibleMembers()->includes(element)).importedPackage)->collect(n \| if n.ownedMember->includes(element) then Set{element.name} else n.elementImport->select(ei \| ei.importedElement = element)->collect(ei \| ei.getName()) endif)->asSet()` | The same names, without recursing for ever through packages that import each other. |
| Namespace::excludeCollisions (body) | `imps->reject(imp1 \| imps->exists(imp2 \| not imp1.isDistinguishableFrom(imp2, self)))` | `imps->reject(imp1 \| imps->exists(imp2 \| imp1 <> imp2 and not imp1.isDistinguishableFrom(imp2, self)))` | Every element is indistinguishable from itself, so every import was excluded and `importedMember` was always empty. |

Not an XMI edit, but needed by these rules: the generator now translates `x.oclIsKindOf(v.oclType())` (used by NamedElement::isDistinguishableFrom, ParameterableElement::isCompatibleWith, ValueSpecification::isCompatibleWith and Classifier::maySpecializeType; Property::isCompatibleWith uses it too but is still not translated, see spec-problems.md) as a run-time check of the metaclass of `v` (`UML_ReflectiveSupport.oclIsKindOfTypeOf`), and it applies the `defaultValue` of stored single-valued attributes (e.g. LiteralInteger::value = 0, ElementImport::visibility = public).
